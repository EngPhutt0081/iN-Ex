# iN&Ex

แอปบันทึกรายรับ-รายจ่าย การเดินทาง การลงทุน และภาษี ใช้บน iPhone/iPad แบบติดตั้งบนหน้าจอโฮม ทำงานออฟไลน์ได้ ข้อมูลซิงก์เข้า Google Sheet ของตัวเอง

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.webmanifest` | ชื่อ ไอคอน และการเปิดแบบเต็มจอ |
| `sw.js` | ทำให้แอปเปิดได้ตอนออฟไลน์ |
| `icon-*.png`, `apple-touch-icon.png` | ไอคอนแอป |
| `Code.gs` | โค้ดฝั่ง Google Sheet (วางใน Apps Script ไม่ได้ใช้บน GitHub) · v3: แท็บงาน, สำรองไป Drive ทุกคืน, Google Calendar, อีเมลสรุปเช้า |

## โหมดแคลอรี่ (kcal)

iN&Ex = **In**come & **Ex**pense และ **In**take & **Ex**penditure ปุ่ม `kcal` มุมขวาบนสลับไปโหมดคุมแคลอรี่

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `body-engine.js` | ฐานข้อมูลแคลอรี่ (เมนู วัตถุดิบ วิธีปรุง) ตัวจับคำ และสูตร BMR/TDEE/งบแคลอรี่ |
| `body.js` | หน้าจอโหมดแคลอรี่ |

- ข้อมูลแคลอรี่เก็บแยกในเครื่อง (IndexedDB คีย์ `body`) ไม่ปนกับข้อมูลการเงิน
- ซิงก์ผ่าน Google Sheet เดิมเป็นรายการ `meta` ชื่อ `body:*` ในแท็บซ่อน `_data` ไม่ต้องแก้ `Code.gs`
- พิมพ์อาหารพร้อมราคา เช่น `กะเพราหมูกรอบ ไข่ดาว 65` จะลงรายจ่ายหมวดอาหารให้ด้วย (ลบอาหารในโหมดแคลอรี่ไม่ลบรายจ่าย)
- ไฟล์สำรอง .json มีข้อมูลแคลอรี่รวมอยู่ด้วย

## หน้าแรก และการสลับโหมด

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `life.js` | หน้าแรก, สลับโหมด, ค้นหา, ต่ออายุ, ซื้อของ, ลดหย่อนภาษี, ตั้งค่า |
| `life.css` | หน้าตาส่วนด้านบน |

- เปิดแอปมาเจอ **หน้าแรก** การ์ดใหญ่ 3 โหมด (เงิน · To Do List · แคลอรี่) ปัดขึ้นแล้วการ์ดจะหดเป็นแถวเดียว และ **วันนี้ของฉัน** (รวมทุกโหมด) กับ **ใกล้ถึง** (30 วัน) เลื่อนขึ้นมา
- ในทุกโหมด แตะชื่อโหมดมุมซ้ายบนเพื่อสลับไปโหมดอื่นหรือกลับหน้าแรก · แว่นขยายมุมขวาบน = ค้นหาทุกอย่าง
- **ปัดจากขอบจอซ้ายไปขวา** = ย้อนกลับ: ถ้ามีหน้าซ้อนอยู่ (แก้งาน หน้างาน MEA ฟอร์มรายจ่าย ฯลฯ) จะปิดหน้านั้นทีละหน้า ถ้าไม่มีจะกลับหน้าแรก
- ตั้งค่าได้ว่าเปิดแอปแล้วไปหน้าแรก / โหมดล่าสุด / โหมดเดิมเสมอ (หน้าแรก → เครื่องมือ → ตั้งค่า)
- **ต่ออายุ**: เก็บชื่อรายการกับวันหมดอายุ (ไม่เก็บเลขบัตร) ใกล้ครบแล้วสร้างงานใน To Do List ให้เอง
- **ซื้อของ**: ติ๊กว่าซื้อแล้ว ใส่ราคา แล้ว “ลงรายจ่าย” ได้ทันที
- **ลดหย่อนภาษี**: ประมาณการจากรายรับ ประกันสังคม กองทุนสำรองฯ และกองทุนที่ติดป้าย RMF / ThaiESG (เพดานปีภาษี 2569) ใช้วางแผนเท่านั้น
- ข้อมูลส่วนนี้เก็บในเครื่อง (IndexedDB คีย์ `life`) ซิงก์เป็นรายการ `meta` ชื่อ `life:*`

แตะชื่อโหมดมุมซ้ายบน → To Do List

| ไฟล์ | ใช้ทำอะไร |

| `todo.css` | หน้าตาโหมดงาน |

- หน้างาน MEA: ปุ่มเปิดโฟลเดอร์ OneDrive · ข้อมูลสัญญา (ผู้รับจ้าง เลขที่ มูลค่า ค่าปรับ วันเริ่ม/สิ้นสุด) นับถอยหลังวันสิ้นสุด เทียบเวลาผ่านไปกับงานคืบหน้า · งวดงาน (ส่งมอบ → ตรวจรับ → เบิกจ่าย) · หลักประกันและประกันความชำรุดบกพร่อง
- **สถิติงาน**: ปิดงานไปกี่งาน เฉลี่ยกี่วัน ทันเป้ากี่ % แต่ละขั้นใช้เวลาเฉลี่ย เอกสารค้างที่ใครนานสุด
- หมวด: MEA / เรียน / ส่วนตัว · งานย่อย · ทำซ้ำ (ทุกวัน/สัปดาห์/เดือน) · ติดธงสำคัญ
- “เร่งด่วน” = เหลือไม่เกิน 2 วันหรือเลยกำหนด (ปรับได้ที่ ตั้งค่า ในแท็บงาน MEA) “สำคัญ” = ติดธง
- ข้อมูลเก็บแยกในเครื่อง (IndexedDB คีย์ `todo`) ไม่ปนกับข้อมูลการเงิน ซิงก์ผ่าน Google Sheet เดิมเป็นรายการ `meta` ชื่อ `todo:*` ในแท็บซ่อน `_data`
- Code.gs v2 สร้างแท็บอ่านง่าย **งาน** และ **ประวัติเอกสาร** ให้ (Code.gs เดิมก็ซิงก์ได้ แค่ไม่มีแท็บนี้)
- ไฟล์สำรอง .json มีข้อมูลงานรวมอยู่ด้วย

## สำรองข้อมูล: มีอยู่ 4 ชั้น ไม่ต้องพึ่ง Claude

1. **ในเครื่อง** ทุกเครื่องที่ติดตั้งแอป
2. **Google Sheet** ซิงก์ภายในไม่กี่วินาทีหลังบันทึก (ปุ่ม “ซิงก์ตอนนี้” กดเองได้)
3. **Google Drive ทุกคืน** โฟลเดอร์ `iN&Ex Backup` มี **Google Sheet เดือนละ 1 ไฟล์** (เช่น `iN&Ex สำรอง 2026-10`) ทุกคืนช่วง 00:00–01:00 Apps Script อัปเดตไฟล์ของเดือนนั้นให้เป็นข้อมูลล่าสุด และเพิ่มแถวในแท็บ `บันทึกการสำรอง` (ปุ่ม “สำรองไป Google Drive ตอนนี้” กดเองได้)
   - ในไฟล์มีแท็บ: สรุปเดือนนั้น · บัญชี (ยอดคงเหลือ) · งาน · ประวัติเอกสาร · `_data` (ข้อมูลดิบทั้งหมด ซ่อนไว้) · บันทึกการสำรอง
   - รอบหลังเที่ยงคืนของวันที่ 1 จะอัปเดตไฟล์ของเดือนก่อนเป็นครั้งสุดท้าย ไฟล์เดือนใหม่เริ่มคืนถัดไป ไฟล์เก่าไม่ถูกลบ
4. **ไฟล์ .json** ปุ่ม “สำรองข้อมูลทั้งหมด (.json)” เก็บไว้ใน Files/OneDrive ได้ ใช้กู้คืนเข้าแอปได้

ทั้งหมดอยู่ใน GitHub และ Google ของคุณเอง

## แจ้งเตือน (Code.gs v3)

- **Google Calendar**: งานที่มีกำหนดส่ง วันตามเอกสาร งวดงาน ครบสัญญา ครบประกันผลงาน และวันหมดอายุ ลงปฏิทินแยกชื่อ `iN&Ex งาน` (เตือนเช้าวันนั้น 07:30 / ก่อน 1 วัน 17:00) อัปเดตภายในประมาณ 10 นาทีหลังแก้งาน · ถ้าปฏิทินนี้ยังไม่ขึ้นใน iPhone: Settings → Calendar → Accounts → Gmail → เปิด Calendars หรือเปิดแอป Google Calendar
- **อีเมลสรุปเช้า**: ส่งเข้าอีเมลบัญชีเดียวกับ Google Sheet ตามเวลาที่ตั้ง (ช่วง 15 นาทีแรกของชั่วโมงนั้น) มีงานวันนี้ งานเลยกำหนด เอกสารที่ต้องตาม สัญญา/งวด/ต่ออายุที่ใกล้ครบ และเงินเมื่อวาน
- เปิด/ปิดและเลือกหัวข้อได้ที่ หน้าแรก → เครื่องมือ → ตั้งค่า → แจ้งเตือน

## อัปเดต Code.gs (ทำครั้งเดียวต่อเวอร์ชัน · ตอนนี้เป็น v3)

ทำบนคอมหรือ iPad (เปิดผ่านเบราว์เซอร์ ไม่ใช่แอป Google Sheets)

1. เปิดไฟล์ `Code.gs` ใน repo นี้บน GitHub → กดปุ่ม **Copy raw file** (ไอคอนแผ่นซ้อนมุมขวาบนของโค้ด)
2. เปิด Google Sheet **iN&Ex** → เมนู **Extensions → Apps Script**
3. คลิกในโค้ดเดิม → กด **Ctrl+A** (Mac: **⌘+A**) → **วาง**ทับด้วยโค้ดที่ก๊อปมา → กดไอคอน **บันทึก** (แผ่นดิสก์) หรือ **Ctrl+S / ⌘+S**
4. ด้านบน ช่องเลือกฟังก์ชัน (ข้างปุ่ม Debug) → เลือก **setupAll** → กด **Run**
   - Google จะขอสิทธิ์ใหม่ (Drive, Google Sheet สำรอง, Calendar, ส่งอีเมล และตั้งเวลา): **Review permissions** → เลือกบัญชี → **Advanced** → **Go to … (unsafe)** → **Allow** (ถ้ามีช่องให้ติ๊กเลือกสิทธิ์ ให้ติ๊ก **Select all**)
   - รอจนด้านล่างขึ้น **Execution completed** ใน Execution log จะมี 3 บรรทัด: สำรองทุกคืน · ปฏิทิน · อีเมลสรุปเช้า
5. **Deploy → Manage deployments** → เลือก deployment เดิม → กดไอคอน **ดินสอ (Edit)** → ช่อง **Version** เลือก **New version** → กด **Deploy** → **Done**
   - ห้ามกด “New deployment” เพราะจะได้ URL ใหม่ ต้องแก้ตัวเดิม URL จะเหมือนเดิม แอปไม่ต้องตั้งค่าใหม่
6. ตรวจ: เปิดแอป → อื่นๆ → ซิงก์และสำรองข้อมูล → กด **สำรองไป Google Drive ตอนนี้** → ขึ้น “สำรองไป Drive แล้ว · iN&Ex สำรอง 2026-10” และในโฟลเดอร์ **iN&Ex Backup** มีไฟล์ของเดือนนี้ไฟล์เดียว
   - ดูตารางเวลาได้ที่ Apps Script → ไอคอน **นาฬิกา (Triggers)** จะมี `nightlyBackup` (ทุกคืน), `calTick` (ทุก 10 นาที) และ `digestTick` (ทุกเช้า)
7. ตรวจอีเมล: แอป → หน้าแรก → เครื่องมือ → ตั้งค่า → **ส่งอีเมลทดสอบตอนนี้**

กู้คืน: ทางหลักคือไฟล์ .json (ปุ่ม “กู้คืนจากไฟล์สำรอง” ในแอป) ส่วนไฟล์ใน Drive มีข้อมูลดิบครบในแท็บ `_data` ที่ซ่อนไว้ ใช้กู้ได้ถ้าไม่มีไฟล์ .json

## ขั้นที่ 1: เปิดเว็บแอปด้วย GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดขึ้น repo นี้ (Add file → Upload files)
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**
3. Branch: **main** / โฟลเดอร์ **/(root)** → Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<username>.github.io/<ชื่อ repo>/`

## ขั้นที่ 2: สร้าง Google Sheet ที่เป็นฐานข้อมูล (ทำบนคอมหรือ iPad สะดวกสุด)

1. เปิด sheets.google.com → สร้างชีตเปล่า ตั้งชื่อ **iN&Ex**
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมด วางโค้ดจาก `Code.gs` แล้วกดบันทึก (ไอคอนแผ่นดิสก์)
4. ด้านบนเลือกฟังก์ชัน **setup** → กด **Run**
   - ครั้งแรก Google จะขอสิทธิ์: **Review permissions** → เลือกบัญชี → ถ้าขึ้น “Google hasn't verified this app” ให้กด **Advanced** → **Go to … (unsafe)** → **Allow** (เป็นสคริปต์ของคุณเอง)
5. กลับไปที่ชีต จะมีแท็บ **ตั้งค่า** ที่มี **รหัสลับ** อยู่
6. ใน Apps Script กด **Deploy → New deployment** → ไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 3: ติดตั้งบน iPhone/iPad

1. เปิดลิงก์แอปจากขั้นที่ 1 ใน **Safari**
2. ปุ่มแชร์ → **Add to Home Screen** → Add
3. เปิดแอปจากไอคอน → แตะแถบ “ยังไม่ได้เชื่อม Google Sheet” → วาง **Web app URL** และ **รหัสลับ** → **เชื่อมต่อ**
4. ทำขั้นที่ 3 ซ้ำบนอีกเครื่อง ใส่ URL และรหัสลับเดียวกัน ข้อมูลจะซิงก์กัน

## อัปเดตแอปในอนาคต

อัปโหลด `index.html` ไฟล์ใหม่ทับไฟล์เดิมบน GitHub ครั้งต่อไปที่เปิดแอปตอนมีเน็ต จะได้เวอร์ชันใหม่เอง ข้อมูลไม่หาย

ถ้าแก้ `Code.gs` ต้อง **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy** URL จะยังเหมือนเดิม

## ความปลอดภัย

- โค้ดใน repo นี้ไม่มีข้อมูลการเงินหรือรหัสลับ
- ข้อมูลทั้งหมดอยู่ใน Google Sheet ส่วนตัวของคุณ และในเครื่องที่ติดตั้งแอป
- อย่าแชร์ Google Sheet หรือรหัสลับกับใคร ถ้าสงสัยว่ารหัสรั่ว ให้ลบค่า `SECRET` ใน Apps Script → Project Settings → Script properties แล้วรัน `setup` ใหม่ จะได้รหัสใหม่
